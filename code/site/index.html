快速开始

四条命令，跑起来一条可以审阅的流水线。安装包自带 pipeline 命令，配置和数据都留在本机。

zsh — pipeline-factory 
# 1. 解压发布物
tar -xzf pipeline-factory-0.2.0.tar.gz
cd pipeline-factory-0.2.0

# 2. 安装（保留已有 config/ 与 var/）
./install.sh

# 3. 启动
pipeline start
# → http://127.0.0.1:4310/

发布物与构建机平台绑定。从 GitHub Releases 下载对应平台的 pipeline-factory-<version>.tar.gz。

zsh — source 
# 依赖 pnpm ≥ 11
cd code
pnpm install

# 生产模式：API 同时托管 Web 构建产物
pnpm build
pnpm start
# → http://127.0.0.1:4310/

配置在 code/config/pipeline-factory.config.json；改前端后要重新 pnpm build 并硬刷新。

zsh — claude backend 
# 安装包不包含 Claude Agent SDK，按需装进安装目录
cd ~/.pipeline-factory/app
npm install --no-save @anthropic-ai/claude-agent-sdk@0.3.283

# 配置里切后端与模型
# "model": { "backend": "claude-agent-sdk" }
# 或指向 SDK 入口：model.claudeAgent.sdkPath

SDK 缺失只会影响 Claude 后端（CLAUDE_AGENT_SDK_UNAVAILABLE）；Codex 后端不受影响。

它替你守住每一步

模型负责生成，Factory 负责边界、证据和停点。每一次交付，都要能被检查。

只读探索

Explorer 恒为 plan 模式，读仓库、查历史、提结构化问题。在你确认之前，它不改一行代码。

契约先行

方案先固化成可审阅的 Plan。缺关键项会自动续探索，只有完整契约才形成 CandidatePlan。

隔离执行

每个 Run 一棵独立 Worktree，基线固定为派发时的 baseCommit。工作区不干净就硬阻断。

门禁验证

按 tag 选择验证命令，结果写进 Run 详情与事件流。不通过就停在那里，不会给你一个“看起来成功”的结果。

事件溯源

需求、Plan、Run、门禁、合并都写事件。SSE 推送实时时间线，历史事件可回放，排障不靠猜。

多后端

Codex App Server 与 Claude Agent SDK 同构，可按角色分工，每个 Project 还能单独覆盖模型与推理档位。

和你现有的工具链一起工作

模型、Git、验证命令和 MCP 工具都不用换。Factory 只负责把它们串成一条有边界、有证据的流水线。

常见问题

先看 pipeline status，再看 pipeline logs -f。大部分问题在这两步里就能定位。

启动后页面打不开，或提示端口被占用？

先运行 pipeline status 确认实例是否已在运行。出现 EADDRINUSE 127.0.0.1:4310 通常表示 API 已经启动，不要重复启动同一实例。页面是旧界面时，确认发布物已升级，然后硬刷新浏览器。

出现 CLAUDE_AGENT_SDK_UNAVAILABLE？

只有使用 Claude 后端时才会出现。把 SDK 装进安装目录的 app/，或在配置里用 model.claudeAgent.sdkPath 指向 SDK 入口文件。使用 Codex 后端不受影响。

出现 SCHEMA_TOO_NEW？

旧程序打开了新版本创建的数据库。运行 pipeline update 升级发布物，不要降级程序版本。 结构版本由 SQLite 的 PRAGMA user_version 自动对齐。

能把服务暴露到局域网或公网吗？

默认只监听回环地址。把 server.host 改成非回环地址时，必须同时配置 server.authToken，否则服务拒绝启动。API 的能力等同于本机 shell、文件系统与 Git， 请先读安装文档里的安全边界，再决定是否对外暴露。

数据在哪里？怎么备份？

运行时数据都在安装目录的 var/ 下：SQLite 数据库、对话图片附件和 Run 的 Git Worktree。 先 pipeline stop，再复制整个 config/ 与 var/。

模型 API Key 存在 Pipeline Factory 里吗？

不存。Factory 不读取也不保存 API Key；Codex 与 Claude 的登录态、端点和凭据由各自的 CLI 管理。
